# Endless Scroll Navigation with Dynamic Routing

This project explores a unique web navigation paradigm: an infinite scroll experience that seamlessly transitions between distinct routes without traditional page loads or clicks. It was built as part of my GSAP learning journey, leveraging modern animation tools to create a fluid, responsive user experience.

## 🎬 Features

- Endless Scroll Navigation with GSAP
- Smooth scrolling experience using Lenis
- GSAP Powered Transitions
- Dynamic Routing

## 🎯 Purpose

This is a personal practice project, created to experiment with animation techniques and transitions in a Next.js environment. It's not intended as a production-ready build, but a sandbox for improving animation fluency and layout flow.

## 🧰 Tech Stack

- [Next.js](https://nextjs.org/)
- [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- [Lenis](https://github.com/studio-freight/lenis) – Smooth scrolling
